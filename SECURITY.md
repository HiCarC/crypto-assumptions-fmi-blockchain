# Security policy

This repository is research code. Everything under `contracts/src/demos/` is deliberately vulnerable. Nothing here is audited by a third party or intended for production.

**Reporting.** If you find an error in the code, the tests or a claim in `CLAIMS.md`, open a private security advisory on this repository (GitHub: Security → Report a vulnerability) or contact the author through the Substack publication *TheKarlC*.

**Third-party systems.** This project does not probe, transact with or test any live network or third-party system. If reading this work leads you to a weakness in a real system, do not exploit or publish it: report it to that system's operator under its disclosure policy.

**Keys.** Every key in this repository is a test key derived from a public string and labelled as such. Do not send value to any address derived from them.
