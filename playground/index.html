What this page is. It reproduces the rules and failure patterns of the reference system so you can watch each check fire. It is not a blockchain node and not the audited code: for that, run make all in the repository. Browsers have no post-quantum signatures, so ML-DSA is simulated with its measured sizes and costs, and labelled where used.

Can a solver reverse SHA-256?

Hide some bits of a message, keep its SHA-256 fingerprint, and recover the bits by plain search in your browser. Then compare with the times three of the best SAT solvers needed for the same task.

12 bits · 4,096 possibilities

    SAT results: full 64-round SHA-256 written as one SAT problem of 71,925 variables and about 319,000 clauses; three random instances per point; 120-second limit (results/sat_scaling.csv). One encoding, one machine: it describes today's tools, not future algorithms.

      Proven for every possible state

      • Settlement moves both legs or neither (Halmos)
      • No transfer without a valid signature (Certora)
      • Each authorisation works only once (Certora)
      • Supply changes only by issuance and redemption (Certora)
      • Nothing moves while paused (Certora)
      • Privileged functions refuse unauthorised callers (Certora)
